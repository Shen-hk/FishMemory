# FishMemory

Android 资讯阅读与内容发布；核心为**原生块式富文本编辑器**（非 WebView），含浏览、互动、草稿与导出发布。

## 功能介绍

- 首页分类与信息流、文章详情  
- 点赞、收藏与本地同步  
- 块状编辑：标题、正文、图片、视频、代码、链接卡片、分割线、列表等  
- 草稿自动保存与草稿列表  
- 文档导出（JSON）与分享  
- （可选）正文 AI 润色：DeepSeek 流式，需在 `local.properties` 配置 `DEEPSEEK_API_KEY`
